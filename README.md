My online presence in one website. Also a place to tinker with tech that interests me.

I designed it to be interchangeable. Backend might change or get a sibling to compare, frontend might change because I like a new library better. I try to keep the content all the time and things to be compatible, but it's not always the case.

## Tech (today)

Bun, Elysia, Astro, Tailwind, SQLite + Drizzle, Satori + resvg, Playwright for e2e. Self-hosted on a single VPS via Coolify.

## Run

Need Bun and Docker.

```sh
bun install
bun run dev
```

Web at `localhost:4321`, API at `localhost:3000`.
